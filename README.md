# Amazone Website Clone 

# Project Overview :- 
This Amazon clone project is a front-end web development endeavor focused on recreating the visual interface and user experience of Amazon's e-commerce platform. Built exclusively with HTML and CSS, the project demonstrates mastery of core front-end technologies and responsive design principles.


# Key Features :- 
1. Responsive Design – Adapts smoothly to desktop, tablet, and mobile screen sizes.
2. Navigation Bar – Includes logo, search bar, menu options, and cart section similar to Amazon.
3. Product Display Sections – Organized product cards and category boxes for easy browsing.
4. Modern Layout Structure – Uses CSS Grid and Flexbox for efficient alignment and positioning.
5. User-Friendly Interface – Clean design with consistent styling, icons, and interactive hover effects.
